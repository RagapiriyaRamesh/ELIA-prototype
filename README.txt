ELIA Admin Portal prototype v9
==============================
Open index.html in any browser (works offline).

62 connected pages. Start at sign-in, or use the journeys on the hub page.
Roles: Admin, Content Manager, Support Team, Sales Assistant.
ELIA is the only booking channel.

New in v9
- Sidebar: no Settings and no Configure group; More holds Business rules, Users, Customers and
  Notifications. No theme icon in the top bar and no switcher arrow on the workspace.
- Support handoff: ELIA assigns each request to one available support person and sends a brief
  (detailed chat summary, what the customer needs, customer details, case link). No time limits,
  no Unattended state, no re-assigning. The support person accepts when ready, contacts the
  customer on WhatsApp, then must report from the case link; ELIA continues from the report.
- Reports are written only from Reports or the case's Report due card, never from Support
  handoff. Report menu: Write report, Edit report, View report, Open case. The report file is an
  optional attachment; every other field is required (Submit stays disabled until filled).
- Case pages have no "Right now" card. Chat sessions: compact Status strip (label, case number
  without an arrow, started, last activity) and What happened.
- Knowledge base: Add website link and Upload document on both tabs. Try them: pick files (PDF,
  DOCX, XLSX, TXT up to 25 MB) or enter a web address and the new item appears at the top of the list
  (kept for the browser session).
- Dashboard shows only related alerts; Notifications has no stat cards.
