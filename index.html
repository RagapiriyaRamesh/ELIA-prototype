The ELIA Admin Portal, connected end to end

ELIA is a white-label AI sales and booking agent for real estate and apartment developers. Customers chat and book on WhatsApp; this portal is where the developer's team watches chats and cases, handles support handoffs and reads bookings. Every screen is its own page. Sign in, use the sidebar, click table rows and buttons — they take you where the real product would. Your theme choice carries across pages.

Try these journeys

Each step links to the page; inside the prototype the same path works by clicking the real buttons.

  • Admin
    Sign in and land on the dashboard
    Sign in→Two-factor verification→Dashboard
  • Admin
    Handle sign-in problems
    Sign-in error→Reset password→Session expired
  • Admin
    Watch a chat session: status, chat, profile, bookings, completed
    Chat sessions→Chat sessions · Chat tab→Chat sessions · Profile→Chat sessions · Booking context→Chat sessions · Completed
  • Admin
    Cases that ELIA handles alone: live and completed
    Cases→Case · ELIA only, live→Case · resolved by ELIA (no handoff)
  • Admin
    A case with one support handoff: assigned with a brief and case link, report, completed
    Case · waiting for support to accept→Case · with support (ELIA following up)→Case · report due (upload report file)→Case · with support (completed)
  • Admin
    A case with two support handoffs
    Cases→Case · two handoffs (2nd live)→Case · agent and support thread
  • Admin
    Support handoff board (no time limits) and rules
    Support handoff→Handoff rules
  • Admin
    Reports: write, edit and view a report (file is an optional attachment)
    Reports→Write report→View report→Edit report
  • Admin
    Open a case and write the report from its Report due card
    Cases→Case · report due (upload report file)→Write report
  • Admin
    Support team: three-dot menu opens View and Edit popups
    Support team→Support team · view popup→Add / edit support person→Delete support person
  • Admin
    Sales assistants: three-dot menu opens View and Edit popups
    Sales assistants→Sales assistants · view popup→Add / edit sales assistant→Sales assistant detail→Delete sales assistant
  • Admin
    Read, edit and delete a booking, then check the calendar
    Bookings→Booking detail→Edit booking→Delete booking→Calendar
  • Admin
    Sales Assistant sees only the calendar
    Sales Assistant · calendar→No access
  • Admin
    Set up availability
    Hours & weekly schedule→Timeslots
  • Admin
    Knowledge base documents: view, download, replace, and upload (works)
    Knowledge base · Documents→Document detail→Replace file→Upload document→Processing failed
  • Admin
    Knowledge base website links: view, refresh, replace, and add a link (works)
    Knowledge base · Website links→Website link detail→Add website link
  • Admin
    Set booking rules and manage users (Settings is in the account menu)
    Business rules→Users→Add / edit user→Settings · My profile→Settings · General
